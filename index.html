GETTING CONNECTED

Use the local network

  1. 01
    Join the ESP32 Wi-Fi

    Connect your phone to PoultryMonitor in Wi-Fi settings.

  2. 02
    Open this dashboard from the ESP32

    For browser access, the dashboard files should be served by the ESP32 at 192.168.4.1. This keeps API requests on the same origin.

  3. 03
    Check your connection

    The app reads /api/status and /api/history every three seconds.

i

Monitoring & alarm acknowledgement

The dashboard monitors conditions and can silence the hardware warning alarm. It does not control fans, heaters, or other poultry-house equipment. If you host this page on a different address, the ESP32 must allow browser CORS requests.
